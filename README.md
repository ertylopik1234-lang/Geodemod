# GD StreamChat — prototype source (Geode / Geometry Dash 2.208)

Includes a first implementation pass of:
- Overlay panel with configurable corner, size and opacity
- English/Russian setting
- Fake chat reactions for death streaks
- Completion message burst and level-name message
- Like counter and rising/shrinking/fading heart animation
- Practice mode disabled

## Important
This is **prototype source code**, not a compiled `.geode` binary. The Geode SDK build has not been run here. Some API names/signatures may need adjustment against the installed Geode SDK 4.0.0 headers before it compiles.
